# spy---see-players-yawn
see players yawn in your own custom games!

## Usage:
`/spy` - spy on the previous few interactions in the current lobby
`/spy player_name` - spy on a specific player's previous interactions across lobbies

## Stores:
Player messages, joins, and leaves, across lobbies per player, and also on the lobby for whatever happened there.

## Why
Could be useful for getting some analytics of whether people are using certain features in your game,
and whether they understand how to play the game. This can then be used to improve your game, and make
it more fun!

## Additional Info
Remember to change the `ownerName` variable to your name. Only you can access it by using commands above.
Go to [spy.js](spy.js) for the code

Enjoy!
